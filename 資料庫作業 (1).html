LIBRARY 查詢練習圖書館借閱系統 · 4 張資料表 · SQLite（瀏覽器內執行）

因此建立 LIBRARY 資料庫，把分館、圖書、會員、借閱紀錄整合，再用 SQL 查出答案。

BRANCH 分館
PK branch_id
name, city
BOOK 圖書
PK isbn
title, category, price, year
FK branch_id → BRANCH
MEMBER 會員
PK member_id
name, join_date
FK branch_id → BRANCH
LOAN 借閱
PK loan_id
loan_date, return_date
FK member_id → MEMBER
FK isbn → BOOK
